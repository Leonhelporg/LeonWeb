Project Summary

LeonBos enterprise anti-detect browser console.

LeonBos 1.0.1 是一款企业级反指纹浏览器控制台，面向多账号资产管理、会话控制、配置编排和运营监控场景。

项目同时提供 Web 控制台与 Electron 桌面壳，支持指纹模板、代理配置、浏览器会话管理，并内置 MCP Server 与插件集成中心。

Core Modules

核心能力

浏览器资产管理

Profiles

创建、查看、删除和启动浏览器 Profile，记录使用次数、最后使用时间和运行状态。

指纹与代理配置

Fingerprint

支持随机指纹生成、模板复用、User-Agent、屏幕、硬件、WebGL、Canvas、Audio 与 WebRTC 防护配置。

Web 与桌面双入口

Console

通过 Express 提供 Web 控制台，并使用 Electron 桌面壳包装，包含 Windows 图标、托盘和安装包构建配置。

集成中心

Integrations

内置 MCPs & Plugins 管理界面，可登记 stdio / HTTP MCP 信息、插件入口、权限、分类和配置，并支持启停、检测与删除。

Use Cases

适用场景

  • 多账号环境与浏览器资产统一管理。
  • 指纹模板、代理和运行参数集中编排。
  • 会话启动、关闭、审计记录与状态监控。
  • 后续 MCP Server 与插件能力的注册治理。

Release

发布信息

当前版本为 LeonBos 1.0.1，项目入口包含 Web 控制台、Electron 桌面版与 Windows 安装包构建脚本。

README 说明当前集成中心只做安全注册表和治理界面，不直接执行外部 MCP 命令或插件代码，后续可扩展受控运行时、权限确认、日志审计和沙箱执行。
